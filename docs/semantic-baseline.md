# 阶段 A：语义基线

本表依据讨论整理。2026-09-20 已在固定上游提交和真实 F35 43 天 canonical 输入上完成现有分钟/编译结构/SimPy 路线基线，并发现一次 `daily-v1` phase 漂移；证据见 [基准报告](../benchmarks/spare_mvp_f35_43day/README.md)。这建立了 oracle，但尚未逐项冻结下表全部语义，也未验证本项目独立执行器。不能用不同输入、不同 profile 或不同随机样本的最终均值接近来替代兼容验证。

## 行为覆盖表

| ID | 要核验并冻结的行为 | 最小证据与验收案例 |
|---|---|---|
| A01 | canonical 输入入口、默认值、版本与来源 | 同一 Project 经唯一 Adapter 导出，固定提交与输入指纹 |
| A02 | 分钟内事件阶段、资源可见性、同刻顺序 | 同分钟返航、故障、维修完成、任务发起的冲突 trace |
| A03 | daily-v1 首次起飞、再次出动、最终检查、跨日飞行 | 跨日任务及当日多次出动的状态与作业链 |
| A04 | 候选、预约、派遣、替补与中止 | 起飞前替补；起飞后中止不自动变成接续任务 |
| A05 | 稳定拓扑顺序串行保障 | 两个就绪作业共享资源，顺序与旧模型一致 |
| A06 | 产品/组件身份、quantity、故障树传播 | 两架飞机共享产品但不共享故障状态；数量与阈值边界 |
| A07 | 飞行暴露量时钟、暂停/恢复、维修或换件后更新 | 地面等待、跨航次剩余寿命、边界取整与浮点行为 |
| A08 | RNG 初始化、调用顺序、采样点和分布变换 | 请求身份与返回值 tape；资源重试不额外抽样 |
| A09 | 分阶段预约、组织候选顺序、多产品与运输策略 | 本地/横向/上级分配与部分预约等待 |
| A10 | 取消、库存归还、唤醒与一次结算 | 取消归还备件后另一个作业可继续，过期完成事件无效 |
| A11 | 时间驱动依赖 | 任务过期、班次切换、跨日检查、预约超时、运输到达 |
| A12 | 指标口径与重复辅助事件 | 可用谓词、分母、停机归因、分钟重复等待事件的映射 |
| A13 | horizon 与未完成状态 | 截止前/恰好截止/截止后事件；未完维修、预约、在途库存 |
| A14 | 确定性及观测隔离 | summary/debug 同业务结果；线程数变化不改变每个样本 |

## 版本边界

| 维度 | 兼容目标 | 后续扩展 |
|---|---|---|
| 时间 | `legacy-minute-v1`，阶段表由源码确认 | `event-time-v2`，另定同刻收敛语义 |
| 随机 | `legacy-sequential-v1`，复现算法与调用顺序 | `named-counter-v1`，稳定身份和分布变换合同 |
| 作业 | `stable-topological-serial` | 显式 DAG 并行策略，属于模型变更 |
| 创作 | Project 派生 IR | IR-native 修订及 agent patch |

这些名称沿用讨论作为设计标签，尚不是已支持的注册 profile。并行分支汇合测试应归属扩展 profile，不能强加给串行兼容基线。

## 阶段 A 完成条件

- 固定可访问的上游 revision、环境和 canonical schema；定位 Adapter、模型 step、RNG、资源及指标源码。
- 至少保存一个可公开使用的导出样例和一组可手算 synthetic fixtures；每个输入标出真实来源，保留 hash 与生成步骤。
- 写出实际 phase 表、随机采样请求格式、结果及 trace 比较规则；每个覆盖项都有证据或明确排除范围。
- 保存旧模型 oracle 输出与重跑命令，标明 instrumentation 是否影响计时。
- 针对首个切片声明支持的行为与明确拒绝的能力；剩余项进入后续切片，不能据局部通过声称全量兼容。

讨论提及的 43 天案例没有随本次任务提供原始 canonical 输入；暂不列为可复现 benchmark，也不以同名合成数据代替。
