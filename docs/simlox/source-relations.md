## Unknown or unsupported from these exports

- No event-level mission/task/failure/maintenance/resource wait trace was exported. Ordering of individual events, scheduling tie-breaks, random draws, and contention resolution are **unknown**.
- No `FailureMode`, `CMLocation`, `TaskBreakDown`, `SubTaskResource`, or `MissionResource` rows were present in these four run 1 exports. Their dictionary definitions are source schema evidence, not example-instance evidence.
- A null field in JSON means the export contains null. It does not prove the model uses null at runtime; a documented default may be applied.
- Units and definitions of report columns not quoted above, custom report settings, and source-to-canonical field mappings are **unknown** here. In particular, no canonical `simulation_inputs` equivalence is asserted.
