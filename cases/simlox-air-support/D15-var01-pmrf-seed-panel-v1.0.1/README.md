# D15.var01 scheduled PM replacement frequency: fixed seed panel

This bounded native CLI case observes `PMReplacement.PMRF=1` and `PMRF=0.5` in matched scheduled system calendar PM models. The [contract](contract.json) froze seeds 2–6 and its acceptance rule before the ten native runs. Each arm has one aircraft, one installed LRU, one local spare, four calendar PM opportunities and a 120-hour horizon. The two arms of each seed differ only in `ProblemDescription.PDESC` and `PMReplacement.PMRF`; the seed variants change only `Control.RSEED` and the description from the excluded [v1.0.0 diagnostic](../D15-var01-pmrf-scheduled-v1.0.0/README.md).

Run `build.py` without `--write` to check the frozen JSON inputs. The [native runner](run_native_ssh.ps1) imports, exports, calculates and exports a default report for each arm. The [selected report runner](run_item_reports_ssh.ps1) exports BASE-01 `ItemResults` from the sealed SXOs. Both require guarded session-0 SSH, the host-wide native mutex and the protected GUI PID 13340, and write immutable raw artifacts under ignored `runs/`. The installed proprietary SIMLOX manual and raw native evidence stay on this host. [Evidence index](evidence-index.json) records 124 raw file sizes and SHA-256 digests across the two runs; `make_evidence_index.py` regenerates it after checking both closures.

All ten inputs roundtripped their populated cells. Native conversion had zero errors and one warning per arm, #108 for enabled simulation logging. PM began at hours 24, 48.5, 73 and 97.5 in every arm. The five `PMRF=1` arms exchanged the LRU at all four opportunities. The five `PMRF=0.5` arms exchanged it 2, 4, 2, 3 and 2 times for seeds 2–6. In each physical exchange, demand coincided with PM start, the installed LRU was removed, a distinct spare was fitted, and the removed LRU completed local item PM before restocking. Every selected report has 240 half-hour BASE-01 item rows; demand, withdrawal, item PM, stock occupancy and zero backorders reconcile with the event logs. All three fixed missions succeeded in every arm, and final selected item stock occupancy was one with no backorder.

The [independent replay](review/independent_replay.py) passed 2,503/2,503 checks and returned `GO_FULL_CONTRACT_BOUNDED`. The [sign-off](cli-scope-signoff-2026-10-04.md) defines the accepted scope. These five fixed seeds do not estimate a general PMRF probability or cover multi-item quantities, unscheduled PM, PM failure modes, other stock networks, GUI behavior or other engines.
