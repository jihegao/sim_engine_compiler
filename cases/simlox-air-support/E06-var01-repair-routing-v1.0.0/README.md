# E06.var01 cumulative direct-repair fraction: two-level boundaries

This bounded case derives from accepted E05 local LRU repair and reissue. It adds the accepted E04 BASE-01 to DEPOT-01 support link, with two hours of transport each way, one-hour direct repair at both stations, base stock one and depot stock zero. The two arms differ only in `ItemRepair[BASE-01].DIRPF`: 1.0 keeps a failed item at the base; 0.0 passes it to the depot. The depot's cumulative `DIRPF` stays 1.0. `build.py`, `contract.json`, `exact-diff.json` and `check_model_delta.py` freeze the model and its exact parent delta.

Both guarded session-0 SSH runs completed native import, export, calculation, report export and roundtrip check with GUI PID 13340 preserved. Raw run files remain in ignored `runs/` paths; the checked-in evidence index contains IDs and SHA-256 seals.

The first failure is shared: installed LRU instance 1 fails at hour 9.25527, aborting the first mission. A local spare is issued at 9.75527 and the aircraft becomes ready at 10.2553 in both arms. The removed item's direct-repair complexity is 0.0874536. With base `DIRPF=1`, it is repaired at BASE-01 from 9.92193 to 10.9219 and returned to local stock. With base `DIRPF=0`, the same item travels to DEPOT-01 from 9.92193 to 11.9219, is repaired there through 12.9219, and returns to BASE-01 stock at 14.9219 after a second two-hour trip. The depot's event-log backorder clears when the item is repaired after three hours; the returned physical item is instance 1.

The arms' later random paths diverge. The local arm has three failures, three system replacements and three local item repairs. The upstream arm has one failure and one item repair; its later two missions succeed. These counts reconcile with each report's System bins and event log, and both finish with one ready aircraft and one local spare. Later failure-count differences are observations of this fixed-seed simulation, not an estimated or causal effect of the repair fraction.

This package accepts the two deterministic boundary fractions only.
