# A08.var04 zero-period simultaneous mission starts

This bounded case derives from the accepted [A08.var01 input](../A08-var01-fixed-count-random-time-v1.0.0/cli-scope-signoff-2026-09-30.md). The [contract](contract.json) changes `OperationProfile.IPER` from 12 to 0 and updates one description label. `ITYPE=RANDOM`, fixed `IQTY=3`, empty `IQTYD`, `IDISP=RANDOM`, `STIM=8`, the fixed two-hour mission template, three available aircraft, 32 replications and hour-36 horizon remain. The [builder](build.py) and [exact diff](exact-diff.json) bind the input to its parent.

The guarded native aggregate run completes import, export, calculation and report generation with zero conversion errors and exact 13-populated-source-table roundtrip. Its event log exposes one replication: three aircraft start separate missions at hour 8 and all succeed and complete at hour 10. The report has 72 aligned half-hour bins, six aircraft mission-operation hours per replication on average and three aircraft ready at the end.

The separately frozen [32-seed matrix contract](contract-seed-matrix-v1.json) and [manifest](seed-matrix-v1.json) supply direct one-replication timelines. Every seed converts and completes the same three-at-8, three-at-10 pattern. The author [replay](review/author-same-time-validation-2026-09-30.json) passes 1,566 checks across source, raw seals, guarded execution, events and ledgers. An [independent read-only replay](review/independent-same-time-2026-09-30.json) passes 1,124 checks, including event-derived aircraft occupancy against every report bin.

Reproduce source files with `python build.py`, `python describe_diff.py` and `python build_seed_matrix.py` from this package. Replay sealed local native runs with `python validate_same_time.py`; native execution requires a fresh versioned run ID, session-0 SSH, the host-wide mutex and preservation of GUI PID 13340. The exact [SSH wrapper](ssh-wrapper-used.ps1) used for the batch contains the original host path and is provenance rather than a portable entry point. Raw native files remain under ignored `runs/`; generated seed inputs under ignored `seed-inputs/` reproduce byte-identically from the manifest.

This scope establishes the observed same-time behavior for one fixed three-mission configuration and 32 explicit native seeds. Other zero-period combinations, GUI visual content and cross-engine equivalence remain unverified.
