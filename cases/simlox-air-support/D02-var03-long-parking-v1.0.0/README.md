# D02.var03 long parking, traditional OPHOURS

This package extends the accepted [D02.var01 installed-LRU case](../D02-var01-traditional-op-hours-v1.0.0/cli-scope-signoff-2026-09-30.md) from a 30-hour to a 130-hour interval without flight. It retains the same traditional `System.OPID` and `Item.OPID` values (`OPHOURS`), failure rate, LRU, spare, repair path, seed and first two missions. Only the third scheduled launch moves from hour 52 to 152, the horizon and result windows extend from 60 to 160 hours, and the description changes. The [contract](contract.json) was frozen before the guarded native run; the [exact parent diff](parent-diff.json) records all table changes.

Build the [native input](native-input.json) with `build.py`. The source-bound `run_native_ssh.ps1` invokes SIMLOX through session-0 SSH, takes the host-wide `Global\SimloxIssue18NativeQueue` mutex and checks the active GUI PID 13340 identity. Import, export, calculation, report and the `check_roundtrip.py` source-table comparison all succeeded in run `d02-var03-long-park-v100-ssh-20260930-01`. Raw artifacts are retained locally under ignored `runs/` and are not distributed with this package.

The first installed-LRU failure occurs at 9.8829; a local spare is issued at 10, the aircraft replacement finishes at 10.5, and the failed item is repaired and restocked at 11.25. The second mission succeeds at 22. No mission or failure occurs between 22 and 152: the aircraft is ready through 151, then completes preparation during 151–152. The delayed mission runs 152–154 and succeeds. The 160-hour report contains 320 half-hour system bins, one failure and one repair, one stock demand and no backorder; the aircraft is ready at the stop. The [author replay](review/author-long-parking-validation-2026-09-30.json) passes 66/66 checks.

This one fixed-seed quiet interval supports only the observed long-parking CLI behavior. The internal `OPHOURS` counter is not directly exposed; other seeds, PM during parking, GUI visual content and cross-engine equivalence remain outside this package. See the [scope sign-off](cli-scope-signoff-2026-09-30.md) for the final publication decision and independent review.
