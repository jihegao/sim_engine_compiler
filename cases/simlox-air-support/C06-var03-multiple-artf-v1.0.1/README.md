# C06.var03 — two simultaneous alternative resource requirements

This versioned Issue 18 case tests one fixed two-aircraft preparation task with two required resource types. The accepted C06 primary-zero/ARTF-two model supplies the first requirement (`P-CREW` or `P-ALT`, ARTF 2). Both new arms add a second requirement (`P-AUX` or `P-AUXALT`), with the second alternative factor set to 1 or 3. Primary capacities are zero; both alternative capacities are two. The two authored inputs differ only in description and that second factor.

The controller launched the two reserved runs once, serially. Their native directories under `runs/` remain local and ignored by Git.
