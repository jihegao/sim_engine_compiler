## Reproduction and limits

Use `build.py --check`, then run the checked input through a **new** run ID via the authenticated loopback SSH wrapper with the exact input SHA-256. Recompute the closure and run `review_readonly.py RUN_DIRECTORY`; never reuse the two recorded run IDs. The existing GUI must remain PID 13340 and responsive.

This confirms explicit MTID recipe selection on one deterministic, item-free, resource-free aircraft path. It does not prove automatic cold/hot switching by sortie number, history or thermal state, resource waiting, faults, GUI-only behavior, cross-engine equivalence or performance.
