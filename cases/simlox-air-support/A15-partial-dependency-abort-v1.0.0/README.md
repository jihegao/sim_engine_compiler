# A15: custom KM accumulation across a deterministic partial mission

This bounded case adds custom `KM` utilization to the published [A14 control and dependency pair](../A14-continuous-end-abort-v1.0.1/cli-scope-signoff-2026-10-01.md). SUPPORT and EXECUTE each start at hour 8 with a different aircraft in the same unit. SUPPORT succeeds at hour 10. In the control, EXECUTE continues and succeeds at hour 12; in the dependent case, SUPPORT's completion aborts EXECUTE at hour 10. The accepted [A15 full-mission SOACC case](../A15-custom-operation-report-v1.0.0/cli-scope-signoff-2026-10-01.md) supplies the custom-operation report method.

The [contract](contract.json) and [exact diff](exact-diff.json) froze four inputs before native execution: control/dependent crossed with `60 KM 1/HOUR` and `240 KM 1/MISSION` for the planned four-hour EXECUTE mission. Only EXECUTE has a KM row. Each child changes its A14 parent only by description, the custom OperationParameter and one MissionTypeUtilization row. The [builder](build.py) checks the accepted parent SHA-256 values and produces byte-stable inputs; the [diff checker](describe_diff.py) verifies the entire four-way source topology.

The [native runner](run_native_ssh.ps1) executed import, export, calculation, default report and exact [source roundtrip](check_roundtrip.py) for each input through session-0 SSH. It held `Global\SimloxIssue18NativeQueue` and guarded GUI Simlox.exe PID 13340/session 1. All four native runs completed with zero conversion errors, 14 or 15 populated source tables roundtripped, nonempty SXOs, and event logs byte-identical to their accepted A14 parent branch. The default reports have 32 half-hour System and Stock bins, zero failure/repair/PM and zero stock demand/backorders, and two aircraft ready at the 16-hour end.

The installed default report omits SOACC. [Settings builder](make_report_settings.py) derives a local Mission Operation `.sxs` from the fingerprinted installed default using the already accepted version-specific descriptor remap. The [report-only runner](report_existing_sxo_ssh.ps1) exported from each sealed SXO without settings fallback. The all-unit KM cumulative totals are **240** for both 8–12 controls and **120** for both 8–10 abort cases. `MissionOperation.SOACC` shows 60 during each active half-hour; `MissionOperationAccumulated.SOACC` adds 30 per half-hour and plateaus at 240 or 120. `MissionOperationTotal` averages the accumulated total over the 16-hour simulation horizon and is not the mission total.

Run `python build.py`, `python describe_diff.py`, `python validate_native.py` and `python make_evidence_index.py` to replay the local source and sealed-output checks. Native runs and report-only exports require the pinned SIMLOX installation and guarded session-0 SSH context; each requires a new unique run ID. The [evidence index](evidence-index.json) contains all eight run IDs and SHA-256 hashes. Raw SXI, SXO, report, logs and local settings copies remain under ignored `runs/` and are not uploaded.

This establishes one deterministic CONTINUOUS dependency abort. The all-unit KM result comes only from EXECUTE's configured utilization; it is not a serial-numbered per-aircraft result. Shared formation disaggregation, failure-driven or fixed/extendable partial missions, suspension/resumption, downstream failure/PM clocks, physical kilometres, GUI rendering and cross-engine parity remain unverified.
