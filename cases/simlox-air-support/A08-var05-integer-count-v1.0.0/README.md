# A08.var05 user-defined integer mission count

This bounded case derives from the accepted [A08.var02 input](../A08-var02-random-count-equidist-v1.0.0/cli-scope-signoff-2026-09-30.md). The [frozen contract](contract.json) changes `OperationProfile.IQTYD` from `<POISSON>` to `COUNT15` and adds an `IntegerDistributions` table with two `<DETERM>` components: count one and count five, each with `PFAC=0.5`. `ITYPE=RANDOM`, `IQTY=3`, `IDISP=EQUIDIST`, `STIM=8`, `IPER=12`, three aircraft and the fixed two-hour mission template remain. Native warning #211 explicitly says the user-defined `IQTYD` overrides `IQTY`. The [builder](build.py) and [exact diff](exact-diff.json) bind this model to the accepted parent.

The guarded 32-replication aggregate run completes four CLI steps and exact 14-populated-source-table roundtrip with zero conversion errors. Its report has 72 aligned half-hour bins, about 6.75 aircraft mission-operation hours per replication and three ready at the end. Its event log exposes only one replication, with five missions at 8, 10.4, 12.8, 15.2 and 17.6 hours. The separately frozen [32-seed one-replication matrix](contract-seed-matrix-v1.json) directly observes 15 one-mission and 17 five-mission runs. Each count places starts evenly over the 12-hour period; every mission succeeds and completes two hours later, with report operation exposure equal to twice its realized count and no shortage, failure, repair or stock demand.

Across the 32 selected seed-level counts, the observed mean is **3.125**, sample variance **4.11290323**, and nominal two-sided 95% Student-t mean half-width **0.731183 missions**. This interval describes the selected native outputs; it does not establish the specified 0.5/0.5 law or independence of seeds. The author [replay](review/author-integer-count-validation-2026-09-30.json) passes 1,249 checks. An [independent read-only replay](review/independent-integer-count-2026-09-30.json) passes 972 checks, including event-derived operation occupancy against every report bin.

Reproduce source with `python build.py`, `python describe_diff.py` and `python build_seed_matrix.py` from this package; replay sealed local runs with `python validate_integer_count.py`. A fresh native execution requires a new run ID, session-0 SSH, the host-wide mutex and preservation of GUI PID 13340. The archived [SSH wrapper](ssh-wrapper-used.ps1) contains its original host path and is provenance rather than a portable entry point. Raw native artifacts remain under ignored `runs/`; generated seed inputs under ignored `seed-inputs/` reproduce byte-identically from the generator and manifest.

This scope covers one two-point distribution, one 12-hour equidistant period, and 32 explicit seeds. Zero count, other integer distribution forms, GUI visual content and cross-engine equivalence remain unverified.
