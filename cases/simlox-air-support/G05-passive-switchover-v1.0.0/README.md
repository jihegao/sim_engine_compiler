This pair derives from the [accepted G04 active one-of-three input](../G04-three-branch-threshold-v1.0.0/README.md). POS-B and POS-A retain their distinct operating-hour failure modes; POS-C has no configured failure mode. A single scheduled mission runs from hour 8 to 34, followed by the unchanged direct half-hour system CM. The paired inputs differ only in description and `TSWOV=0` versus `0.5` hour.
