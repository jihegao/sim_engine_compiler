# C04.var01 — aircraft and preparation-crew shortages

This package classifies three **already accepted** C04 1.0.0 fixed-source CLI runs. It creates no model input and calls no simulator. The [corrected contract](contract.json) pins the accepted source, the C03 staffing parent, all three final native closures and their raw evidence. The original v0.1.0 contract and its independent NO_GO remain excluded.

All three runs request two aircraft for one mission ordered at h7.5, with a declared latest launch of h8.5. The `crew-equal` control has two aircraft and one P-CREW: aircraft 0 works from h7.5 to h8, aircraft 1 then receives the released crew and works to h8.5; the two-aircraft mission succeeds at h9.5. The `aircraft-missing` arm has one aircraft **and two crew**, allocates and prepares only aircraft 0, then cancels at h8. The `crew-zero` arm retains two aircraft but has no crew: both availability tests fail, no crew is booked, both waiting tasks stop on h8 cancellation, and both aircraft return ready. The cancellation line has no structured reason code.

The [author replay](check_reclassification.py) passed **19,234/19,234** checks twice with identical LF verdict bytes. The [separate independent replay](review/independent-verdict.json) passed **16,663/16,663** checks. They verify 25 accepted C04 source files against local and Git identities, 33 selected C04 raw seals plus 11 direct C03 parent raw seals, source differences, native roundtrips, physical event order and every cell of six report tables (**5,210 per arm**). Against the control, the missing-aircraft and zero-crew reports differ respectively in **0/4/158/0/218/5** and **0/4/16/0/219/5** cells in contract table order.

The aircraft-missing source changes `SystemDeployment.QTYPS` **2→1** and P-CREW `ResourceAllocation.RQTY` **1→2** jointly; it does not isolate an aircraft-quantity effect. Crew-zero changes only P-CREW `RQTY` **1→0**. These observations do not establish a general cancellation code, deadline rule or GUI behavior. The [scope assessment](cli-scope-signoff-2026-10-07.md) records the limits. The evidence index seals the final source and raw chains; independent publication review remains pending.
