# J09.var05 — task-free PM turnaround scale, matched native pair

This package isolates `ScaleFactors.SCPMT` in a one-aircraft, seed-1, 60-hour calendar preventive-maintenance case. Both arms derive from accepted D03 by clearing `PMLocation.TID` so the authored `PMT=1` is used, and appending the same six-field ScaleFactors row. The only inter-arm input change is `SCPMT` from 1 to 2. The pre-run [contract](contract.json) and [exact diff](exact-diff.json) pin this before native execution. The prior [v1.0.0 run](../J09-var05-pm-tat-scale-v1.0.0/excluded-diagnostic.md), which retained a one-hour task breakdown, had no positive effect and remains excluded.

Two guarded session-0 SSH native runs completed with preserved GUI PID 13340 and sealed local raw artifacts. The control PMs run 24–25 and 49–50; the scaled PMs run 24–28 and 52–56. Native subtasks explicitly say planned work lasts **1 hour** in control and **4 hours** with `SCPMT=2`. The four-hour result exceeds the simple two-hour interpretation of a factor of two. This case records the observed timing; the number of internal applications of the factor is unverified.

All three missions succeed in both arms. The control report is byte-identical to D03. The scaled report has eight total aircraft-hours of PM versus two in control; PM occupancy and ready-state changes reconcile across 120 half-hour System bins. All 120 Stock bins and the mission summary match. Both arms end ready with no active PM. The [author replay](author-native-validation-2026-10-04.json) passes 4,703 checks; independent replay and bounded acceptance are recorded in [the signoff](cli-scope-signoff-2026-10-04.md).

Use `build.py` and `describe_diff.py` without `--write` to verify the frozen sources. `run_control_ssh.ps1` and `run_scaled_ssh.ps1` require a fresh run ID, an SSH session-0 process with `sshd.exe` ancestry, the host-wide native queue, and the unchanged GUI. Never rerun an existing ID or treat the local ignored `runs/` as tracked source. The scope is this task-free PMT fallback input, fixed seed, scale pair and 60-hour horizon; no general multiplier law, other PM task form, GUI visual result or cross-engine equivalence is claimed.
