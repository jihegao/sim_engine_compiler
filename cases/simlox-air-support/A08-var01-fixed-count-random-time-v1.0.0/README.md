# A08.var01 fixed-count random mission times

This bounded case derives from the accepted [A02 repeated-mission input](../A02-single-aircraft-repeated-missions/cli-scope-signoff-2026-09-29.md). The [frozen contract](contract.json) sets `OperationProfile.ITYPE=RANDOM`, `IQTY=3`, `IQTYD` empty, `STIM=8`, `IPER=12`, and `IDISP=RANDOM`. Three aircraft are deployed, so clustered starts do not create an initial shortage. The parent's fixed two-hour mission template, travel fractions, zero failure rate, and hour-36 horizon remain. The [builder](build.py) and [exact diff](exact-diff.json) bind this input to the accepted A02 source.

The guarded native aggregate run uses 32 replications. Its report has 72 aligned half-hour bins, six aircraft mission-operation hours per replication on average, and three aircraft ready at the end. The native event log exposes only one replication's timeline. We therefore froze a [separate seed-matrix contract](contract-seed-matrix-v1.json) and [32-seed input manifest](seed-matrix-v1.json), then ran 32 serial one-replication native simulations. Each log shows three distinct mission starts within [8,20), followed by successful completion two hours later. All 96 starts are retained with seed identities in the [author replay](review/author-random-time-validation-2026-09-30.json). Their observed mean is 13.9386496875 hours, sample variance 12.0453941163 hours squared, and nominal two-sided 95% Student-t mean half-width 0.7032182 hours. All 32 ordered triples differ. The seed-1 timeline matches the aggregate run's logged timeline, but the batch and aggregate are distinct experiments.

The author replay passes 1,566 checks across source, guarded invocation, SHA-256 raw seals, conversion, exact import/export roundtrip, mission events, report ledgers, and timing statistics. A [separate read-only replay](review/independent-random-time-2026-09-30.json) passes 905 checks without importing the author implementation. Native raw files remain under ignored `runs/`; generated seed inputs are reproducible from [the generator](build_seed_matrix.py) and are ignored under `seed-inputs/`.

Reproduce source files with `python build.py`, `python describe_diff.py`, and `python build_seed_matrix.py` from this package; replay local sealed runs with `python validate_random_time.py` and the independent reviewer. Native execution requires a fresh run ID, the session-0 SSH guard, the host-wide mutex, and preservation of the GUI PID. The exact small SSH wrapper used for the seed batch is archived as [ssh-wrapper-used.ps1](ssh-wrapper-used.ps1); it contains the original host path and is provenance, not a portable entry point.

This scope demonstrates one fixed quantity of three, one 12-hour random-time period, three available aircraft, 32 explicit one-replication seed runs, and one 32-replication aggregate. The explicit seed set is a convenience matrix; its nominal confidence interval describes observed spread and does not prove uniformity or independence of the native generator. Random quantity, equidistant times, zero period, invalid input combinations, GUI visual content, and cross-engine equivalence remain unverified.
