# E12.var03: BASE-02 individual repair override

This bounded case derives from the accepted [E12.var02 two-fault shared group source](../E12-var02-two-fault-group-v1.0.0/README.md). The new task has one-third-hour remove and two-thirds-hour fit subtasks. Only `ProblemDescription`, `SystemRepair`, `Tasks` and `TaskBreakDown` change; the other 28 source tables, including failure modes, missions, stock, transport and seed, remain fixed. The [contract](contract.json), [exact diff](exact-diff.json) and [native input](native-input.json) were frozen before the native run.
