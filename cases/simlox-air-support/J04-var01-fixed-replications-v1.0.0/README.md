# J04.var01 fixed native replications

This bounded case derives from accepted `J02.var03@1.0.0` Poisson formation-count seed-01 input (SHA-256 `2edd37fb063ac7f1d5a1ee17ea10779ac699fce75f4288e81b4026a3ff8a933f`). Only `Control.NREPS` changes from 1 to 16 and optional `Control.TCLEV` is made explicitly 0.0. The installed SIMLOX manual says TCLEV=0 disables confidence stopping, so NREPS fixes the replication count. Seed 1, twelve aircraft, the random count distribution, schedule, report interval and horizon remain.

One excluded diagnostic with a complete native run failed at its evidence closure because the first runner used PowerShell's automatic `$input` variable inside `Seal`; its raw files are preserved and separately identified. The corrected diagnostic passed. Two fresh accepted session-0 SSH runs then passed import/export/calc/JSON report with zero converter errors, 14 populated-table business roundtrips, 22 raw SHA-256 seals and source-pinned validators. Both reports show NREP=16 and the same aggregate rows: MTMF/MSTF/MSUF/STMF=1, relative errors=0, 72 aligned System and Stock bins, average 3.125 operating aircraft (1.5625 inferred two-aircraft formations) at hour 8–10, 6.25 average aircraft flight hours and twelve ready at the horizon. The corrected accepted pair uses fresh IDs 03/04. The first accepted pair IDs 01/02 is superseded because its original contract mislabeled 3.125 aircraft as formations; its source files and raw evidence are retained. Independent read-only replay passed 2,306/2,306 checks on the corrected pair with 22 raw seals. The two current reports are semantically identical; their first-replication event logs are byte-identical to each other and to the accepted parent seed-01 event log.

The manual says ENLOG writes only the first replication. The native report contains aggregate rows, so this package does not infer the other fifteen per-replication mission counts or event timelines. RSMTMF=0 describes the reported mission-time fraction for this panel; it does not say the random mission count has zero variance. The accepted J02.var03 32-seed panel independently observed count variance, but it is a distinct experiment.

The runner requires authenticated session-0 SSH, the host-wide Issue #18 mutex, exact source and installed manual/dictionary/executable hashes and preservation of GUI PID 13340. Ignored `runs/` contains raw files. `validate.py RUN_DIRECTORY` replays one accepted run, `validate_pair.py` replays both, and `evidence-index.json` lists the run IDs and SHA-256 seals. The proprietary manual and dictionary are pinned but not included.

TCLEV>0 stopping, an NREPS cap under nonconvergence, thread changes, per-replication event exposure, GUI visual behavior and cross-engine parity remain unverified.
