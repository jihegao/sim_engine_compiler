# G02.var03 fixed-seed diagnostic, excluded

This initial QTYPM/ENVF frequency probe derives from published G02.var01, sets both position mode frequencies to 50,000 per million `OPHOURS`, and compares baseline `POS-B` QTYPM=1/ENVF=1 with separate QTYPM=2 and ENVF=2 arms. Each arm uses 256 native replications at seed 1. All three guarded session-0 SSH runs completed import, export, calculation and JSON report export with zero converter errors and exact 18-table roundtrip. The raw run directories are local and ignored; `evidence-index.json` seals their 36 raw files.

Reported aggregate failures and repairs per 256 replications were 125 in baseline, 199 with QTYPM=2, and 197 with ENVF=2. These are one fixed-seed descriptive observations. The first-only event logs contained no failures, and the aggregate report did not provide per-replication variability or position attribution. The pre-run contract required uncertainty analysis, so these three probes did **not** meet acceptance and are excluded from the publication index. The separate [v1.0.1 seed panel](../G02-var03-quantity-environment-v1.0.1/README.md) provides the predeclared matched-seed analysis used for bounded publication.
