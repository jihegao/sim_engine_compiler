# D10.var01: two-mission preventive maintenance counter

This bounded CLI case derives from the accepted [D04 operation-hour PM](../D04-flight-hour-pm-v1.0.0/cli-scope-signoff-2026-09-30.md). It gives one aircraft five fixed missions: 8–12, 16–17, 20–21, 48–49 and 52–53 hours. One `MS2` PM with `MaterielPM.OPID=MISSIONS` and `PMINT=2` has a one-hour `INSPECT` subtask at the base. Native PM work occurs at 17–18 after the second completed mission and 49–50 after the fourth. This controls the [paired three-counter case](../D10-var02-multi-counter-v1.0.0/README.md).

The [pre-run contract](contract.json), [frozen native input](native-input.json), [exact D04 parent diff](exact-diff.json), [scope signoff](cli-scope-signoff-2026-10-01.md) and [evidence index](evidence-index.json) define the accepted scope. Run `build.py` and `describe_diff.py` to verify source bytes, `validate_native.py runs/d10-missions-v100-ssh-20261001-01` for author replay, and `review/independent_readonly.py` for separate raw replay. The guarded session-0 SSH runner is [run_native_ssh.ps1](run_native_ssh.ps1). Original SXI/SXO, event log and report remain local under ignored `runs/d10-missions-v100-ssh-20261001-01/`.
