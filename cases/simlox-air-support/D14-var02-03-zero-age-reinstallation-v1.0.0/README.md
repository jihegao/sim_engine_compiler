# D14.var02–03: stocked item zero age and reinstallation

This package derives two matched native inputs from accepted [D14.var01](../D14-var01-monitored-item-pm-v1.0.1/cli-scope-signoff-2026-10-02.md). The [contract](contract.json) declares the hypothesis and acceptance criteria before the native runs; [exact-diff.json](exact-diff.json) records the complete table delta. The paired arms differ only in `MaterielPM.MONIT` (`Y` versus `N`) and descriptive `ProblemDescription.PDESC`. Both start with one installed LRU and one stocked spare, no `Prelife`, and three two-hour missions. A one-time `SYS-SWAP` system PM after the first mission exchanges the mounted item for the spare. Separate `LRU-OP3` item PM is due after three operation hours.

`build.py` verifies or regenerates the frozen inputs; `describe_diff.py` checks their exact delta. The guarded `run_native_ssh.ps1` requires session-0 loopback SSH, `sshd.exe` ancestry, the host-wide `Global\SimloxIssue18NativeQueue` mutex, active GUI PID 13340, and pinned source, parent closure, executable, manual, and dictionary bytes. It runs import, export, calculation, JSON report, and exact-row roundtrip sequentially using hidden CLI processes. Native raw files stay in ignored `runs/`; use a fresh run ID for any future execution. `validate_native.py` replays accepted raw files without SIMLOX. `independent_replay.py` is the separate reviewer's implementation.

The observed monitored arm runs `SYS-SWAP` at hour 10 and `LRU-OP3` at hour 34; the converted arm runs the same tasks at hours 10 and 22. In the monitored arm the stocked item ID 1 enters service at hour 10, has two operation hours by hour 22, triggers item PM after its next two-hour mission at hour 34, and is replaced by the overhauled original ID 0. The converted arm creates new item objects on removal and reaches its separate system-level item PMID threshold at hour 22. Both arms complete all missions and end ready with one spare and no backorder. This isolated timing and identity contrast supports D14.var02's bounded zero-initial-age interpretation and directly shows physical reinstallation for D14.var03. SIMLOX did not directly report per-item counter age. The run ends before another mission, so it does not establish whether the reinstalled original retained its PM counter.

The installed proprietary SIMLOX manual, dictionary, executable, and raw native files remain local. The [evidence index](evidence-index.json) publishes their hashes and local raw seals; [sign-off](cli-scope-signoff-2026-10-02.md) records the accepted scope and limits.
