# F03.var02 two-base LRU opening-stock comparison

This bounded pair adds the accepted F03.var01 second-base structure to the accepted F02.var02 risk fleet. Both arms have three `TEACH-AIR-01` aircraft across BASE-01 and BASE-02, one staffed local crew and maintainer at each base, a common depot, and a 60-hour window. The only paired business change is `StockAllocation(AIR_BASIC, TEACH-LRU-01, BASE-01).STSIZ` 0→1. Descriptive text also differs. [Contract](contract.json), [builder](build.py), and [exact diff](exact-diff.json) freeze the source and parent fingerprints.

Both native arms see the same BASE-01 LRU demands at hours 23.74 and twice at 48.2231. Depot-only stock creates three two-hour base backorders (six item-hours). The forward-stock arm issues a local LRU immediately for the first demand and one late demand, leaving one two-hour backorder (two item-hours). Depot replenishment still occurs, and physical LRU IDs differ across arms. The first BASE-01 repair completes at 24.24 with a forward spare instead of 26.0733; its next BASIC mission launches at 24.75 instead of 26.5733. The late BASIC mission cancels in both arms. BASE-02 aircraft ID 2 succeeds on its mission at hours 8–10, with no BASE-02 stock demand. Three aircraft are ready at hour 60 in both arms, and the final summary metrics happen to match despite different intermediate readiness.

## Reproduce

`python build.py` and `python describe_diff.py` verify the frozen inputs and hashes. Run the two arms serially under session-0 SSH using `run_native_ssh.ps1 -Arm depot_only|forward_spare -RunId <new-id>`. The runner requires the `sshd.exe` ancestor, host-wide `Global\SimloxIssue18NativeQueue` mutex, active GUI PID 13340/session 1, pinned sources and installed executable, strict converter diagnostics, exact populated-table roundtrip, and raw-file closure. Use unique immutable run IDs. `python validate_native.py` replays the accepted pair; the [independent replay](review/independent_replay.py) uses separate read-only code. The [evidence index](evidence-index.json) identifies local run IDs and SHA-256 seals; raw SXI/SXO, logs and reports stay ignored locally.

This one-seed comparison demonstrates BASE-01 opening LRU stock use and its observed downstream effects. It does not establish BASE-02 stock demand, alternative stock classes, transport-route contention, item-specific routing, aircraft transfer, resource relocation, larger networks, GUI visuals or cross-engine equivalence.
