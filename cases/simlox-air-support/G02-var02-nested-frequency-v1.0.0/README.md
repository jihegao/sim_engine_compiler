# G02.var02 nested material-position frequency propagation

This case derives from the published G02.var01 two-position aircraft model and adds a child material position under `POS-B`: `TEACH-AIR-01 → POS-B → POS-B-CH → TEACH-LRU-01`. `FM-POS-B` is rebound to `POS-B-CH`; its direct half-hour system CM location remains the same. `POS-A` stays a separate direct branch. Both position failure-mode frequencies are set to 50,000 per million `OPHOURS` with 256 replications over the existing 36-hour three-mission schedule. The manual's `MaterielStructure` description on physical pages 251–253 states that quantity transfers task frequency to system level and that ancestor `ENVF` values are inherited by subitems.

The predeclared panel uses seeds 2–13. Within each seed, nested baseline has `POS-B` ancestor `QTYPM=1` and `ENVF=1.0`; the quantity arm changes only ancestor `QTYPM` to 2; the environment arm changes only ancestor `ENVF` to 2. The child has `QTYPM=1`, `ENVF=1.0` in all arms. The per-arm description varies for provenance. `contract.json` pins the hypothesis and directional analysis before native execution; `exact-diff.json` verifies each of the 36 full inputs against the accepted parent.

All 36 guarded session-0 SSH runs completed import, export, calculation, report export, and exact 18-populated-table roundtrip, with zero conversion errors and warning #108 for enabled ENLOG. Each has 72 aligned half-hour System and Stock bins and 12 raw SHA-256 seals. Fourteen first-replication logs show `FM-POS-B` on `POS-B-CH` with `POS-B` in its connection path. `runs/` remains local and ignored; `evidence-index.json` records all run identities and raw hashes.

Aggregate System `NFAIL=NREPT` mean counts per 256 replications are 137.08 at nested baseline, 205.33 with ancestor quantity two, and 202.75 with ancestor environment two. Both paired contrasts are positive for every one of twelve matched seeds. Their mean increases are 68.25 and 65.67 per 256; the predeclared exact one-sided sign p is 0.000244 for each, below the Bonferroni 0.025 threshold. All 36 non-description native ResultSummary, SystemResults and StockTotalResults tables match the published one-level G02.var03 panel for the same seeds and arms. That exact panel match is a post-run observation; the contract does not assert general structural equivalence.

`build.py` generates inputs from the pinned G02.var01 parent. `run_native_ssh.ps1` guards the host mutex and GUI PID 13340; `run_panel.ps1` serializes the panel. `validate_panel.py` checks raw seals and paired outcomes. The independent read-only replay passed 1,659 checks across all 36 runs and 432 raw seals, with verdict `GO_BOUNDED_SEED_PANEL`; its script and report are in `review/`. PR gates are pending. ENLOG covers only one replication per run, and the aggregate report does not attribute failures by position. Physical replacement, other structure shapes and rates, GUI visual behavior and cross-engine parity remain unverified.
