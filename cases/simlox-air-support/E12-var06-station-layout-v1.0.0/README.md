# E12.var06: Station level and index metadata

This bounded case derives from the accepted [E12.var05 asymmetric-stock parent](../E12-var05-base02-zero-opening-stock-v1.0.0/README.md). It adds `Station.LEVL=BASE` for `BASE-01` and `BASE-02`, `LEVL=DEPOT` for their common support station, and `LINDX` values 2, 1 and 1 respectively. Only these six cells and `ProblemDescription` change. All stock, support edges, repairs, failures, missions, seed and the 36-hour horizon remain fixed. The installed SIMLOX manual pages 323–324 describe `LEVL` and `LINDX` as controls for the support organization plot; the two bases support from a distinct depot level, avoiding the manual's inconsistent same-level support example.

Raw files remain in ignored `runs/` and are hashed in [the evidence index](evidence-index.json).
