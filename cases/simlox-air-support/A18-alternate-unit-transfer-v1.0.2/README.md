# A18 one alternate-unit transfer, v1.0.2

This bounded case derives from the accepted [A17 two-unit parent](../A17-multi-unit-group-v1.0.0/README.md). `TEACH-UNIT` has one aircraft but schedules a two-aircraft mission. `TEACH-UNIT-2` has two ready aircraft and an explicit zero-quantity `ALT-IDLE` profile. The configured model adds one `AlternateUnit` row pointing from the ordinary unit to `TEACH-UNIT-2`; the absent control omits that row. Both keep `Control.ENALU=Y`. The two inputs otherwise differ only in description. [The frozen contract](contract.json), [builder](build.py), and [exact diff](exact-diff.json) define the model before native execution.

The configured native event log shows the hour-7 mission first allocating the ordinary aircraft, moving wholly to `TEACH-UNIT-2`, releasing that ordinary aircraft, and allocating both alternate aircraft. The alternate pair launches at 8, succeeds at 10 and returns to its unit. With no `AlternateUnit` row, the original one-aircraft allocation waits and cancels at 8.33333 without launch. The two native ResultSummary rows respectively report all four mission factors at 1 and 0. The configured System bins integrate four operating aircraft-hours; the control integrates zero. Both end with three ready aircraft, no faults, repairs, stock demand or backorders.

The [dated sign-off](cli-scope-signoff-2026-10-01.md) records native run IDs, raw closure hashes, review decisions and exact limits. The raw `.sxi`, `.sxo`, logs, reports and invocation/closure records remain ignored under `runs/`. The runner requires authenticated session-0 SSH, the host-wide native mutex, the pinned local executable and preservation of GUI PID 13340. Reproduce the checked inputs with `python build.py` and the exact lineage with `python describe_diff.py`; run `python validate.py` for read-only evidence replay.

The earlier [v1.0.0 default-profile probe](../A18-alternate-unit-transfer-v1.0.0/README.md) and [v1.0.1 ENALU switch probe](../A18-alternate-unit-transfer-v1.0.1/README.md) are explicitly **not published**. v1.0.1 shows that `ENALU=N` did not suppress transfer in this model even though it roundtripped; this case therefore uses the structural `AlternateUnit` contrast. The native converter also emits notice #320 that alternate-unit modelling is obsolete and recommends unit groups. This one-seed case does not test multiple alternates, priority ordering, delayed readiness, failure during preparation, GUI presentation or cross-engine parity. Issue #18 remains open.
