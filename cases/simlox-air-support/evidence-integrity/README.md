# Published source-byte audits

Run `../tools/audit_published_source_bytes.py` from this repository to compare source SHA-256 pins in tracked case evidence indexes with local files and published Git blobs. The default ref is `origin/simlox/main`; `--staged` compares the Git index before commit. Pin definitions are read from the current working-tree indexes, so a historical-ref comparison assumes those definitions have not changed. The tool recognizes source lists, direct and versioned source maps, `source_files_sha256`, `files_sha256`, and tracked `files` maps. Its summary reports exactly how many pins it examined and how many ignored or untracked paths it skipped. Package-specific replay remains responsible for raw native run seals.

[The E12 repair manifest](e12-source-byte-repair-2026-10-05.json) records 51 original byte pins and their previous LF-normalized Git hashes across eleven E12 packages. Exact-path attributes and restaging recover the original bytes without changing contracts, evidence indexes, or raw runs. The prior blobs remain at the recorded prior ref. The E12 stage checks 178 source pins, eleven original run invocation/closure pairs, and 132 raw artifact seals. Its wider source audit reported 13 non-E12 byte mismatches, addressed by the next repair.

[The remaining-source repair manifest](remaining-source-byte-repair-2026-10-05.json) records the 13 C09/J03/J04 files and the prior/new attribute and index hashes. Exact-path rules restore the original source bytes. Three packages pin their own `.gitattributes`, so their current evidence indexes update only that attribute pin; the previous index blobs and all old pins remain available at the manifest's prior ref. Seven packages have 241 checked source pins, 137 run invocation/closure pairs, and 1,498 raw seals. The staged audit covers 3,997 tracked source pins across 301 indexes with no remaining disk or Git mismatches in the supported fields. It does not audit ignored raw files outside those seven package replays.
