# E12.var04: item-group by station-group repair reference

This bounded case derives from the accepted [E12.var03 BASE-02 SystemRepair override](../E12-var03-base02-system-repair-override-v1.0.0/README.md). The sole physical `TEACH-LRU-01` gets `GIID=LRU-GRP`; the sole support depot `DEPOT-01` gets `GSTID=DEPOT-GRP`. The existing one-hour `ItemRepair` row changes its keys from the individual `IID` and `STID` to `LRU-GRP` and `DEPOT-GRP`. Its time and all physical failure, stock, transport, mission and SystemRepair inputs stay fixed. Only five cells in four source tables change, including description. The installed SIMLOX dictionary permits `ItemRepair.IID` to reference `Item.GIID` and `ItemRepair.STID` to reference `Station.GSTID`.

The [contract](contract.json), [exact diff](exact-diff.json) and [native input](native-input.json) were frozen before native execution. Run `build.py` and `describe_diff.py` without flags to check the source. `run_native_ssh.ps1` requires guarded session-0 SSH, the host-wide Issue #18 mutex and active GUI PID 13340. Native run ID: `e12-var04-item-station-group-v100-ssh-20261003-01`. `check_roundtrip.py` checks import/export and `validate_native.py` replays native behavior. Raw artifacts stay in ignored `runs/`; the evidence index seals them after independent review.

Failed physical LRU IDs3, 4 and 5 still arrive at `DEPOT-01` and undergo one-hour direct repair. The native event log is byte identical to the individual-reference parent. `ResultSummary` and every row of the 72 half-hour `SystemResults` and 72 half-hour `StockTotalResults` tables also match; only `ProblemDescription` differs. The BASE-02 one-hour SystemRepair override, depot-local backorder, four aborted/two successful missions and h36 boundary remain observable.

One physical item and one depot belong to the respective groups. This establishes only that the crossed group references resolve for this one member pair. It does not test fanout, overlapping individual/group repair rows or precedence, other item/station combinations, GUI visuals or cross-engine behavior.
