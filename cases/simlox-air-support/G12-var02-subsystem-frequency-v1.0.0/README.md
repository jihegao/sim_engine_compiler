# G12.var02: subsystem quantity and environment factor

This bounded native panel starts from the accepted [G12.var01 two-child composite](../G12-var01-two-subsystems-v1.0.0/cli-scope-signoff-2026-10-03.md). The common model gives child B a direct `System.FRT=50000` per million `OPHOURS`, computes the top system's rate from its children, and gives child B a half-hour direct repair. Child A's CAL24 PM, one deployed top aircraft, and the 60-hour mission schedule stay fixed. For each seed 2–13, the baseline has child-B `SystemStructure.QTYPM=1, ENVF=1`; the quantity arm changes only `QTYPM` to 2, and the environment arm changes only `ENVF` to 2, apart from provenance text. Each arm has 256 replications. The [contract](contract.json) and [36-input manifest](input-manifest.json) were frozen before native execution.
