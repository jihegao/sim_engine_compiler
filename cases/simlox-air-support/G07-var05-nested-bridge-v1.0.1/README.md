This case extends the accepted [G07.var03 bridge-block failure](../G07-var03-bridge-failure-v1.0.0/cli-scope-signoff-2026-10-03.md). It replaces BR=POS-B with a named two-position series RBD containing POS-B and new healthy POS-F. POS-F has the same LRU type and `G04-OPS` mode but no failure mode; B/A failures, rates, mission, seed and repairs remain fixed. The [contract](contract.json) and [exact diff](exact-diff.json) pin the seven changed tables. The installed manual allows an RBD as a bridge component and requires both series members to function.

The first frozen [candidate](../G07-var05-nested-bridge-v1.0.0/diagnostic-note.md) supplied `BROPM=G04-OPS` for the nested RBD. Native conversion returned error #462, so that run is diagnostic only. v1.0.1 differs from it solely by leaving `BROPM` empty; physical positions and the nested series are otherwise identical.

The revised guarded SSH0 run completed native import, export, calculation, report export and an exact 24-populated-table roundtrip with zero converter errors/notes and reviewed warning #108. B failed noncritically h8.62763 and A noncritically h16.7498; the mission succeeded h34 and both direct CM tasks completed h34.5. The event log is byte-identical to the accepted direct-BR control. Its 72-bin report reconciles two failures/repairs, no stock movement and one terminal ready aircraft. [Author replay](author-validation.json) passes 89/89 and [independent read-only replay](review/independent-validation-2026-10-03.json) passes 2,875/2,875. The [evidence index](evidence-index.json) seals 13 raw native files locally under ignored `runs/`.

The source-defined nested series becomes nonfunctional when B fails, while both direct bridge routes remain; after A, UL+UR remains. The native event log reports system criticality and outcome but does not label nested block state or active path. This is one healthy-F series nested in BR under one seed, not a test of every nested RBD type, failure combination, online maintenance, GUI drawing, population reliability or cross-engine parity.
