# Reproduction and custody

Use the bundled Python interpreter with `-X utf8 -B`. From this package, `build.py`, `copy_context.py`, `source_gate.py --mode live`, and `self_check.py` read and verify the source and accepted evidence. `test_converter_gate.ps1` runs a clearly synthetic converter-text test. These commands do not invoke SIMLOX. `source_gate.py --mode sealed` is the append-aware read-only gate after publication: it checks the owned 496-entry local archive and distinct base Git blob, then requires the live catalog to preserve metadata, the first 496 entries and unique publication IDs.

The canonical `source-inventory.json` and `prelaunch-manifest.json` are written once by root after author and independent methods are frozen. The root-owned runner uses an actual SSH session 0 PowerShell 5 `-File` call for a zero-native preflight. An independent GO_PRELAUNCH must bind the exact preflight receipt and frozen source map before root can dispatch the one unique native run. The six serial stages are import, export, roundtrip check, calculation, JSON report, behavior check. The calculation log is sealed and its exact converter warnings are checked before JSON report.

Original stdout/stderr bytes, actual integer exits, process IDs, session IDs, UTC order, invocation and closure are separately sealed. A later published result requires independent replay and content review. Existing accepted parent and dependency run directories remain fixed; never relaunch them for convenience. This package does not establish general transfer timing, priority, GUI or cross-engine behavior.

The v1.0.0 prospective package remains excluded and must not be relaunched. This v1.0.1 source inventory has an explicit, narrow allowance for later package-root publication documents, index builders and numbered inert custody copies. Once those files exist, the final evidence index must enumerate and hash the entire actual publication set; the prelaunch source inventory remains byte-stable. The two full app-context originals at historical indices 147 and 148 are required at their pinned local paths for full provenance replay and are never publication copies. The package includes separately pinned, case-specific filtered derivatives and a transformation map; these bytes are not presented as identical to the originals.
