# J07.var05: unit and mission-type report slice, v1.0.0

This bounded case tests native mission-result tables selected by operational unit and mission type. It derives from accepted A17 1.0.0. Two one-aircraft units remain members of `TEACH-GROUP`, but each owns a different fixed mission profile. `MISSION-A` at `TEACH-UNIT` and `MISSION-B` at `TEACH-UNIT-2` each request one aircraft at hour 8 for two hours. The [frozen contract](contract.json) and [exact source diff](exact-diff.json) constrain the model to four changed input tables.

The fresh native run `j07-unit-type-v100-20261001-01` imports, exports, calculates and emits a default JSON report through session-0 SSH under the host mutex. It preserves GUI PID 13340, roundtrips all 15 populated source tables, and converts with zero errors. Both missions launch at 8, succeed at 10 and return one ready aircraft to each unit. The report has 72 System and 72 Stock half-hour bins over 0–36. The raw `.sxi`, `.sxo`, logs, JSON reports, invocations and SHA-256 closures remain ignored under `runs/` on the pinned host.

The installed default report settings omit mission detail tables. [The settings builder](make_report_settings.py) creates local `.sxs` copies from the fingerprinted installed `Default.sxs`, changing six mission table flags and the serialized unit/mission selector strings. It does not edit the installed file. Guarded report-only exports on the sealed child `.sxo` give native all-unit, per-unit and per-type totals. Each unit and each mission type contributes one requested, started and successful wave, two mission-hours and two aircraft-hours; both pairs sum to the all-unit two waves and four hours of each kind. The group selector returns no mission rows for the unit-owned profiles. The same settings on the accepted A17 group-owned `.sxo` produce one `TEACH-GROUP` wave and four aircraft-hours, while its member-unit selectors return no mission rows. The CLI report therefore exposes the profile owner in this bounded pair; membership alone does not establish a rollup of member-unit missions.

The [dated sign-off](cli-scope-signoff-2026-10-01.md) records the exact scope and review. J07.var05's planned group aggregation remains open. Regenerative denominator exclusion, mid-mission partial outcomes, GUI rendering and cross-engine parity remain unverified.

## Replay

Run `python build.py`, `python describe_diff.py`, `python make_report_settings.py`, `python validate.py` and `python review/independent_readonly.py` in this directory. The two validators inspect sealed raw files and do not run SIMLOX. For fresh native execution, use `run_native_ssh.ps1 -Variant unit-type-pair -RunId <unique-id>` through authenticated session-0 SSH. `report_existing_sxo_ssh.ps1` and `report_group_parent_ssh.ps1` export fresh reports from the pinned accepted `.sxo` files with `-Selector` and a unique `-RunId`; they enforce the same host queue and GUI identity. The installed SIMLOX and default settings fingerprints must match the contract.
