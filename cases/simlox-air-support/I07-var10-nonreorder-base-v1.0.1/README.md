The v1.0.0 runner's frozen sole-#108 gate stopped before child selected-report export, so that version remains an excluded diagnostic.

The new ten-table selected JSON is byte-identical to the original control report. The original complete event logs are also byte-identical, including every physical item-stock transition: depot IDs 0/1/2 and base ID3 at opening; base ID3 and depot ID0 issued at hour 10; depot IDs5/6 delivered at hour 11; depot ID0 arrives at base at hour 12. All 72 selected half-hour depot bins agree, with nominal stock 4, on-hand 3 before hour 10, 2 until hour 11, then 4. The reorder marker is one in the hour-10 bin and zero elsewhere.

The result supports ignored ROSIZ at this **one existing BASE stock row without reorder data**. It does not establish behavior for a missing stock row, other item or station types, a different strategy, GUI operation, or Issue #18 as a whole. The [scope signoff](cli-scope-signoff-2026-10-05.md) and [evidence index](evidence-index.json) link the old excluded run and the new report-only closure.
