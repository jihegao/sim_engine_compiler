This bounded CLI case derives from the accepted [E01 local-spare system replacement](../E01-local-spare-explicit-replacement-v1.0.0/cli-scope-signoff-2026-09-29.md). It complements the separate [G01.var03 secondary DP case](../G01-var03-dp-discard-reorder-v1.0.0/cli-scope-signoff-2026-10-01.md). The [pre-run contract](contract.json), [native input](native-input.json), [exact parent diff](exact-diff.json), [signoff](cli-scope-signoff-2026-10-01.md), and [evidence index](evidence-index.json) define the accepted observation.

Run `build.py` to verify the source bytes against E01, `describe_diff.py` to verify the exact eight-table delta, and `validate_native.py runs/g01-var03-du-v100-ssh-20261001-01` for author replay. The [independent checker](review/independent_readonly.py) replays raw source and results without importing author acceptance. Original SXI/SXO, event log, report, invocation and closure remain local under ignored `runs/g01-var03-du-v100-ssh-20261001-01/`.

The E01 installed LRU is replaced by a primary DU with the same failure rate. The DU repair row is removed; a DEPOT reorder position, one-hour lead and two-hour route to base are added. In one fixed-seed run, SIMLOX discards the failed DU, replenishes base stock from depot stock, and supplies a new reorder item to the depot. The report's aggregate `NDF=1` does not count every physical base/depot demand, which the event log identifies separately. Other reorder policies, seeds, stations, combined DU/DP structures, GUI-only behavior and cross-engine equivalence remain unverified.
