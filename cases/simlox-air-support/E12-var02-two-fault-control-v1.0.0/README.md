This bounded control derives from the accepted [E12.var01 explicit two-base source](../E12-var01-explicit-two-bases-v1.0.0/README.md). Native run ID: `e12-var02-two-fault-control-v100-ssh-20261003-01`. `check_roundtrip.py` checks import/export and `validate_native.py` replays native behavior. Raw outputs stay in ignored `runs/`; the evidence index seals their bytes after independent review.

The final half-hour report samples one ready aircraft and zero backorders; BASE-01 repair completes exactly at the h36 horizon and the event log then records two ready aircraft.
