# C02.var03 — both resources sufficient

This package proposes a **read-only, source-bound classification** of four already accepted C02 1.0.2 final `-02` CLI runs. It creates no model input and requests no new SIMLOX execution. The [corrected contract](contract.json) pins the source and closure hashes; the [author checker](check_reclassification.py) replays them without modifying raw evidence.

The two available-resource inputs both provide P-CREW x1 and E-GSE x1 to INSPECT SEQ1. Their task topologies differ: `single-both` runs one 30-minute INSPECT, while `serial-both` runs 10-minute INSPECT followed by 20-minute SERVICE with no explicit resource demand. The available runs book and release both resources around INSPECT, then launch the same aircraft at h8 and succeed at h10. Combined resource occupancy is 60 versus 20 resource-minutes. The matched equipment-zero controls retain each topology but set E-GSE capacity to zero; both wait without a partial booking or work and cancel at the observed h7.58333.

The author checker verifies the four accepted input/closure/invocation chains and 44 raw SHA/size seals; local versus published Git bytes of the accepted C02 source are checked separately, including `.gitignore` CRLF/LF identities. It checks authored roundtrips, event order and every cell of six report tables (5,210 per run). The two available reports differ only in the h7 ResourceResults `NRUM` bin and ResourceResultsTotal `NRUM`; the zero-control log and report bytes are equal.

This is a comparison of **different authored task decompositions**, not an isolated one-cell experiment or a general task-topology equivalence claim. The old v0.1.0 contract and its independent NO_GO remain excluded. The [independent replay](review/independent-postrun-2026-10-07.md) passed 54,584/54,584 checks. The [scope note](cli-scope-signoff-2026-10-07.md) states its gates and limits. Evidence-index sealing and independent publication review remain required before publication.
