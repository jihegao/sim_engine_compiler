# J07 fixed-count denominator with regenerative children

This bounded case derives from accepted A07 regenerative relief and adds two scheduled fixed demands to the same two-aircraft unit. The eight-hour regenerative period at 8–16 is unchanged. A one-aircraft fixed mission at 20 succeeds at 24; a three-aircraft demand at 28 cannot start with two aircraft and cancels at 28.3333. The [frozen contract](contract.json), [builder](build.py), and [exact diff](exact-diff.json) bind the three-table input delta and pre-run 1-of-2 fixed-count hypothesis.

The native log records **four successful regenerative children** and **one successful fixed mission**. A guarded local report export exposes `RegenMissionResultsTotal.NMSTA=NMSUC=4` with `NMREQ` undefined, while `FixedMissionResultsTotal` has `NMREQ=2`, `NMSTA=NMSUC=1`. The global `MSTF=MSUF=0.5` therefore follows the two fixed scheduled demands; it does not count the four regenerative child successes. The time factors retain regenerative contribution: `MTMF=12/16=0.75` and `STMF=18/28≈0.642857`. The estimated regenerative system-time demand is 12 aircraft-hours and its observed operation is 14; the successful fixed mission adds four, while the denied three-aircraft demand adds 12 requested and zero accomplished aircraft-hours.

Run `j07-fixed-regen-v100-20261001-01` completed five guarded session-0 SSH steps, preserved GUI PID 13340, exactly roundtripped 13 populated source tables, and converted with zero errors. Its 72 System and Stock half-hour bins integrate 18 aircraft operation hours, no failures, repairs or stock backorders, and two ready aircraft at the hour-36 end. The raw `.sxi`, `.sxo`, logs, JSON reports, invocations, local `.sxs` settings and SHA-256 closures remain ignored under `runs/`. The [dated sign-off](cli-scope-signoff-2026-10-01.md) records their IDs and hashes.

The installed `Default.sxs` omits fixed and regenerative detail tables. [The settings builder](make_report_settings.py) makes local copies with eight mission table flags enabled and a length-prefixed selector; it does not edit the installed file. Guarded report-only exports from the sealed child and accepted A07 parent `.sxo` files supply the detailed native counts and control. Author and independent reviewers replay the raw files read-only.

## Reproduce

Run `python build.py`, `python describe_diff.py`, `python make_report_settings.py`, `python validate.py`, and `python review/independent_readonly.py` from this directory. Fresh native execution requires the pinned local installation and a unique run ID via `run_native_ssh.ps1 -Variant mixed-demand -RunId <id>` in authenticated session-0 SSH. The two report-only runners accept `-Selector` and a fresh `-RunId` on the sealed child or A07 parent `.sxo`; they enforce the host queue, source hashes, and GUI identity. The report runners are pinned to the sign-off source SXO runs. The installed manual and dictionary remain local.

This case has one deterministic seed, no failures or support-resource contention, and one deliberately impossible fixed demand. Regenerative child counts under failures, mid-mission partial outcomes, GUI rendering and cross-engine parity remain unverified. Issue #18 remains open.
