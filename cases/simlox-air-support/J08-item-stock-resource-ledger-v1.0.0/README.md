## Reproduce

The scripts require the pinned Windows SIMLOX installation, accepted local parent raw evidence, Python runtime path, active GUI PID 13340, and session-0 SSH access. Run IDs must be new; every run directory is immutable. Native commands acquire `Global\SimloxIssue18NativeQueue`, run CLI processes hidden, and check that the GUI is preserved. From this package:

1. Run `python build.py`, `python describe_diff.py`, and `python make_full_report_settings.py`. Verify their printed hashes against the contract and amendment.
2. Over SSH to `127.0.0.1`, run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <package>\run_native_ssh.ps1 -RunId <new-native-id>`. For a new native result, update the literal SXO/closure hashes in a **copy** of `run_item_report_full_ssh.ps1` after reviewing its sealed closure.
3. Run that report-only script over session-0 SSH with a new report ID. Review the resulting `ItemResults` table before acceptance. Run `python validate_native.py` against the frozen acceptance IDs, or adapt its paths and expected hashes explicitly for the new sealed runs. A separate reviewer must replay without importing that author validator.

The [author replay](author-validation-2026-10-04.json) passes 517/517 checks. The [evidence index](evidence-index.json) identifies local raw artifact IDs, paths, byte counts and SHA-256 hashes; native results and proprietary selectors are ignored by Git and must remain local.

This is one two-aircraft, single-seed, one LRU/SRU chain and aggregate-resource slice. It establishes one tracked depot item position and one base backorder.
