# G02.var03 quantity and environment frequency propagation

This case extends the published G02.var01 two-position aircraft model. Its controlled common model sets both position-specific `FailureMode.FRQ` values to 50,000 per million `OPHOURS`, with 256 replications and the existing 36-hour, three-mission schedule. For each of twelve predeclared seeds (2–13), the baseline uses `POS-B` `MaterielStructure.QTYPM=1` and `ENVF=1.0`; the quantity arm changes only `QTYPM` to 2; the environment arm changes only `ENVF` to 2. The per-arm description identifies provenance and is excluded from the business-factor comparison. This tests documented frequency propagation, not physical replacement count or equivalence of the two factors.

The installed SIMLOX manual, physical pages 250–253, describes material structure quantity and environment factors. `contract.json` pins its SHA-256, the installed dictionary, executable, parent input, the 36-run seed panel, and the analysis before the panel was run. The proprietary sources are not copied into this package.

All 36 native session-0 SSH runs completed import, export, calculation, JSON report export, and exact 18-populated-table roundtrip. Each had zero conversion errors, warning #108 for the enabled event log, 72 aligned half-hour System and Stock bins, and a source/12-file raw closure. `runs/` is local and ignored; `evidence-index.json` identifies the immutable raw evidence and hashes.

The author replay measures aggregate System `NFAIL` as count per 256 replications. Mean counts across the twelve seeds are 137.08 for baseline, 205.33 for quantity two, and 202.75 for environment two. Paired mean increases are 68.25 (Student t 95% interval 63.51–72.99) and 65.67 (61.31–70.02) per 256 replications. Both contrasts are positive in all twelve seeds; each exact one-sided sign-test p is 0.000244, below its predeclared Bonferroni threshold 0.025. These are model- and panel-bounded observations, not exact rate multipliers. The event log covers only the first replication of each 256-replication run, so its position-specific events are classified separately from the aggregate.

`build.py` deterministically generates a seed/arm input from the pinned parent. `run_native_ssh.ps1` guards the host mutex and GUI PID 13340 for each run; `run_panel.ps1` serializes the predeclared panel. `check_roundtrip.py` checks source identity. `validate_panel.py` replays raw seals and the predeclared analysis. The independent read-only verifier passed 1,586 checks across the 36 runs and 432 raw seals, with `GO_BOUNDED_SEED_PANEL`; its script and report are in `review/`. PR gates are pending.
