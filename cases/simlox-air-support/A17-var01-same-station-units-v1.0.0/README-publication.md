# A17.var01: two explicit units at one station

This package records one bounded child of the accepted A17 two-unit model. The only business input change is `Unit[TEACH-UNIT-2].STID` from `BASE-02` to `BASE-01`; `ProblemDescription.PDESC` labels the child. Both units remain explicit. The 36-hour horizon, seed, aircraft quantities, group and mission definitions are unchanged.

One approved native dispatch completed four native commands and two pure checker stages with exit 0 and empty stderr. The original run's author receipts passed the exact 33-table/20-row/203-cell input, 33-table/38-row/387-cell export, predeclared primary 60-line/52-timed-line physical trace, and all 4,044 typed report cells. The converter log passed the 17-line grammar with only warnings #108 and #126, zero errors, and exact Input/Output/File paths. The unchanged independent reader replayed 25 recovered copies against the original run and all 173 frozen prelaunch roles and returned `GO_BOUNDED`. The separate receipt-bound review decision is `GO_BOUNDED_POSTRUN` in [independent-postrun-go.json](review/independent-postrun-go.json).

The observed primary trace is the contract's `unit0-controller0-return01` arm. Its full physical ledger covers aircraft identity, unit ownership, mission assignment, flight, task, return and ready events. Seven other prospective log arms were declared diagnostics and would have stopped this child; they were not native runs. The oracle was not revised after observing the run. The authoritative bounded scope is [independent-postrun-scope-signoff-v2.md](review/independent-postrun-scope-signoff-v2.md); the earlier root-level signoff remains preserved as historical wording.

This result is limited to two explicit units assigned to `BASE-01` in this one source model and seed. It does not establish generic station controller indexing or tie ordering, implicit-unit behavior, other station capacities, GUI behavior, cross-engine equivalence, performance, all of A17.var01, or Issue 18 completion.

The 53 owned prelaunch files and 173-role manifest are frozen. Full sealed replay requires the 61 prelaunch mandatory originals, 15 self-captured zero-native preflight originals, 39 new native/PURE/transport originals, and 25 byte-equal recovered run copies. The package includes byte-equal copies of only two small native log files and 77 small postrun proof/context files; their custody maps preserve original paths and hashes. Nineteen publication proof files (15 capture receipts/streams and four source methods), plus their external proof manifest, remain mandatory on the controlled host. Bulky SXI/SXO, roundtrip and report originals remain host-bound; a published checkout alone cannot establish a full replay. Both failures, their original streams and corrected successor methods remain separate history; neither was a second native attempt.
